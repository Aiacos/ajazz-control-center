\<threat_model>

## Trust Boundaries

| Boundary                             | Description                                                                  |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| plugin -> switchToProfile inbound    | Untrusted plugin-supplied profile/device tokens cross into ProfileController |
| watcher -> applicationDid\* outbound | Host-sourced foreground app id flows out to plugins                          |
| OS wake -> systemDidWakeUp           | OS power signal triggers an outbound fan-out                                 |

## STRIDE Threat Register

| Threat ID        | Category               | Component                                              | Disposition | Mitigation Plan                                                                                             |
| ---------------- | ---------------------- | ------------------------------------------------------ | ----------- | ----------------------------------------------------------------------------------------------------------- |
| T-34-04-01       | Denial of Service      | malicious plugin spams switchToProfile / focus thrash  | mitigate    | Idempotent no-op-on-identical switch (CR WR-01 pattern) + upstream debounce; no repaint when target==active |
| T-34-04-02       | Information Disclosure | foreground app name leaked to plugins                  | mitigate    | Deliver applicationDid\* ONLY to registered plugins over loopback WS (PLGSEC-03); never broadcast (V4)      |
| T-34-04-03       | Tampering              | untrusted app-id / switchToProfile token used as a key | mitigate    | Treat as match/lookup token only; V5 validate+bound; never eval/exec/shell-out                              |
| T-34-04-04       | Elevation of Privilege | plugin switches a profile it should not                | mitigate    | V4 access control: reuse the cross-plugin denial pattern; scope the switch to the plugin's allowed profiles |
| T-34-04-05       | Information Disclosure | over-long applicationDidLaunch path                    | mitigate    | Length-bound the path before send (mirror logMessage 2048 cap)                                              |
| \</threat_model> |                        |                                                        |             |                                                                                                             |
