<objective>
Replace the `AJAZZ_ALLOW_UNTRUSTED_PLUGINS` env var as the primary trust path with a first-class in-app affordance: an app-level "Allow unsigned plugins" setting (QSettings-persisted) AND a per-plugin "Allow this plugin" action in `LoadedPluginsPage.qml` (which today shows only read-only trust chips at `:153-198`). Tampered plugins (Ed25519-invalid — `VerifyVerdict::Refused` after the Plan 01 split) are NEVER allowable from the UI; only unsigned (`VerifyVerdict::Unsigned`) is consentable. The env var remains functional for headless/CI runs.

Purpose: Closes the trust-UX portion of PLUGIN-16. Depends on Plan 01 (the Unsigned/Tampered verdict split that gives the UI a distinct "tampered" state to refuse). Runs in Wave 3 parallel with Plan 03 (disjoint files).

Output: `allowUnsignedPlugins` Q_PROPERTY (persisted, mirroring `onlineCatalogEnabled`); `untrustedPluginsAllowed()` becomes env-var-OR-setting; a per-plugin "Allow this plugin" Q_INVOKABLE that records consent + re-promotes/rediscovers; QML toggle + per-plugin allow action with tampered rows visually distinct and non-allowable; a Catch2 test asserting the setting gates Unsigned installs and tampered stays refused.
</objective>
