<objective>
Fix the confirmed 5-arg drop regression on encoder dials and touch-strip zones so dropped plugin actions persist their `actionId` routably, and add STRICT affordance gating to all three drop targets (keys, dials, touch zones) so mismatched controller drops are visually rejected with `drag.accepted=false`.

Output: Fixed drop calls, affordance gating on 3 components, a C++ persistence round-trip test, an extended QML drag-drop test.
</objective>
