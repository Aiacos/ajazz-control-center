From src/app/src/pi_bridge.hpp (ajazz::app::PIBridge):

```cpp
PIBridge(PropertyInspectorController* controller,  // nullptr is valid for the persistence path
         QString pluginUuid, QString actionUuid, QString contextUuid,
         QObject* parent = nullptr);
Q_INVOKABLE void setSettings(QString const& json);        // writes <AppData>/plugins/<plugin>/settings/<context>.json
Q_INVOKABLE void getSettings();                            // emits didReceiveSettings(json) or "{}"
Q_INVOKABLE void setGlobalSettings(QString const& json);  // writes <AppData>/plugins/<plugin>/global.json
Q_INVOKABLE void getGlobalSettings();                      // emits didReceiveGlobalSettings(json) or "{}"
signals:
  void didReceiveSettings(QString json);
  void didReceiveGlobalSettings(QString json);
```

Persistence facts (verified, pi_bridge.cpp):

- Path root = `QStandardPaths::writableLocation(QStandardPaths::AppDataLocation)` + `/plugins/<pluginUuid>/...`
- `isSafeUuidComponent` rejects empty, >256 chars, control bytes, `/` `\`, `.`, `..`, and any embedded `..`.
- On rejected uuid: `setSettings`/`setGlobalSettings` log + return WITHOUT writing; `getSettings`/`getGlobalSettings` emit `"{}"`.
- 1 MiB cap (`kMaxSettingsBytes = 1LL << 20`); JSON validated before write.
- `setSettings` ignores `controller_` (`(void)controller_`), so `controller==nullptr` is supported.
