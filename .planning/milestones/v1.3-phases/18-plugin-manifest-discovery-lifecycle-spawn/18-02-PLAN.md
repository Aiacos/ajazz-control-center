## Trust Boundaries

| Boundary                   | Description                                                                 |
| -------------------------- | --------------------------------------------------------------------------- |
| host -> spawned node child | The host constructs the argv + program for an untrusted plugin's node child |
| OS PATH -> node resolution | The resolved `node` binary is an external user-managed dependency           |

| T-18-ARGV        | Tampering / Elevation | node argv injection                             | mitigate    | argv is built and passed as a QStringList to QProcess::start(program, args) — NEVER concatenated into a shell string; codePath and uuid travel as discrete tokens so a hostile codePath/uuid cannot inject extra flags or shell metacharacters (the manager in 18-04 uses the list form; this plan only builds the list) |
