## Trust Boundaries

| Boundary                                                    | Description                                                               |
| ----------------------------------------------------------- | ------------------------------------------------------------------------- |
| untrusted .sdPlugin package (zip + manifest + code) -> host | Discovery/extraction/spawn all ingest attacker-controlled package content |
| host -> spawned child process (node/native)                 | The host launches an untrusted plugin runtime it must contain + reap      |
| HTML plugin page (Chromium) -> host bridge / network        | The plugin's index.html runs in-process and may try hostile navigation    |
| host -> plugin socket (exitApp)                             | Shutdown writes to a possibly-closed plugin socket                        |
