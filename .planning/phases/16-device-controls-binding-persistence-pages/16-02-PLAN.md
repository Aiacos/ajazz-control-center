## Trust Boundaries

| Boundary                                                | Description                                                                                                                                                                         |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| QML editor edit -> ProfileController -> on-disk JSON    | Editor field values cross from QML into the C++ Profile and onto disk via the atomic core writer. The profile is user-authored/local config (same trust model as a keyboard macro). |
| profile id -> save file path                            | The profile id becomes part of the save filename; an attacker-influenced id could attempt path traversal.                                                                           |
| profile imagePath (on reload) -> QImage load on repaint | A profile-supplied image path is loaded and pushed to the device on repaint.                                                                                                        |
