<objective>
Build a standalone `PluginManifest` struct and a pure `parsePluginManifest()` parser plus a
`manifestRunnableHere()` validation gate for the Elgato Stream Deck v6 schema with the AJAZZ
extensions. This is a genuinely NEW parser — `plugin_catalog_model.cpp` parses a catalogue FEED
(`CatalogEntry`), NOT on-disk `manifest.json`; there is no existing manifest reader anywhere
(RESEARCH finding #2 / Pitfall 1). Both Phase-18 discovery and any future catalog enrichment call
this one parser.

Purpose: PLUGIN-06. The parser + gate are the first thing the Wave-2 PluginManager needs before it
can decide what to spawn.
Output: `plugin_manifest.{hpp,cpp}` (pure, Qt-Core-only, no WebEngine/WebSockets dep) + a
`PluginManifestTest` suite over JSON fixtures, wired into the unit target.
</objective>
