the Stream Dock family (AKP03 / AKP153 / AKP815) and prove it hardware-free with a
per-family `MockTransport` byte test. This is the DEVICES-10 deliverable: the SAME

`StreamDockInputService` to be capability-generic (`dynamic_cast` to `IDisplayCapable` /

implicitly assume AKP05 geometry, then pins the family behaviour with byte tests. The
per-family backends and their image transforms already exist and are byte-tested; this is
generalisation, not new protocol work, and no wire code is touched.

(geometry read from `displayInfo()`/descriptor), and a new
`tests/unit/test_stream_dock_family.cpp` that is the Phase-24 gating proof. Live
confirmation for whatever family member is physically connected is Phase 25.
