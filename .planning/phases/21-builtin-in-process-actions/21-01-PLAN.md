## Trust Boundaries

| Boundary                                                 | Description                                                                                                                                                                                                                            |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| profile-authored action -> IInputSynthesizer -> OS input | A profile-bound `system.hotkey`/`plain.text` action synthesizes OS-level key/text - the same trust model as a keyboard macro; the profile is local/user-authored, the synthesis output is intentional (carried from Phase 15 T-15-03). |
| optional global-hook CAPTURE -> host action trigger      | A global hotkey that TRIGGERS an action is a keylogger-shaped surface; it must be OFF by default and only active behind an explicit enable (LOCKED anti-feature).                                                                      |
| /dev/uinput device node                                  | The Linux backend writes to a privileged device node; EACCES must degrade to a safe no-op-return-false, never crash, and never trigger a system mutation from tooling.                                                                 |
